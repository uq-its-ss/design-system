# Vision 6 template guidance

These guidelines for Vision 6 are designed to support staff in creating effective, on-brand emails. By using the templates, you're helping maintain brand consistency and compliance while creating a seamless experience for all audiences.

## Getting Started

### How to access templates

1. Navigate to **Messages** > **New message**
2. Select **Shared** from the email template dropdown
3. Select:
   - **Single message email**
     - Standard
     - Event
     - Alert
   - **E-Newsletter**
4. Click **Open template**

## Template Types & Rules

### Single-message email

A text-based standalone email is a simple, single-purpose email designed to communicate one key message. This format uses minimal design elements and focuses on clear, direct content with a single primary call-to-action, if required.

Use this template for standard email communications when you have a single topic or message such as an important alert, promoting an event or deadline, or sending a simple reminder.

#### Standard email

Use for routine communications and general announcements.

**Guidelines:**

- Max one primary call to action
- Max 3 hyperlinks in text
- Do not use hero images
- Do not use in-content images
- Do not use content sections
- Contact footer required
- Remove social icons

**Component usage:**

- ✅ **Required:** UQ header, Sender header, Contact footer
- ⛔ **Do not use:** E-newsletter header, Hero image, In-content images, Content sections, Social contact footer

#### Event email

Use for event invitations and promotions.

**Guidelines:**

- Max one primary call to action
- Max 3 hyperlinks in text
- Hero image recommended for engagement
- Use in-content images if needed
- Use content sections if needed
- Social contact footer required
- Do not use standard contact footer

**Component usage:**

- ✅ **Required:** UQ header, Sender header, Social contact footer
- ⭐ **Recommended:** Hero image
- ⚪ **Use if needed:** In-content images, Content sections
- ⛔ **Do not use:** E-newsletter header, Contact footer

#### Alert email

Use for important alerts and emergencies.

**Guidelines:**

- Max one primary call to action
- Max 3 hyperlinks in text
- Do not use hero images
- Do not use in-content images
- Do not use content sections
- Contact footer required
- Remove social icons for important alerts or emergencies

**Component usage:**

- ✅ **Required:** UQ header, Sender header, Contact footer
- ⛔ **Do not use:** E-newsletter header, Hero image, In-content images, Content sections, Social contact footer

### E-Newsletter

An e-newsletter is a structured email template designed to share multiple updates, stories, or opportunities within a single communication. This format typically includes multiple sections, headings, images, and several calls-to-action.

Use this template for newsletter email communications, such as when you are sharing multiple announcements, providing a recurring update, or showcasing a range of events or opportunities.

**Guidelines:**

- Max one primary call to action and one related link per story
- Hero image required
- In-content images recommended
- Content sections recommended for grouping stories
- E-newsletter header required
- Social contact footer required
- Do not use standard contact footer

**Component usage:**

- ✅ **Required:** UQ header, Sender header, E-newsletter header, Hero image, Social contact footer
- ⭐ **Recommended:** In-content images, Content sections
- ⛔ **Do not use:** Contact footer

## Working in Vision 6

### Adding text into email messages

To avoid unintended formatting being carried into your email, type content directly where possible. If copying content, use a plain text source (such as Notepad) to strip formatting.

### Links

When adding links ensure that **'Open in a new window'** is selected.

**Link best practices:**

- **Purpose-driven links:** Include hyperlinks that directly align with the email's main goal
- **Descriptive call to actions:** "Download the guide" or "Access the course materials" rather than "Click here"
- **Diversity of links:** Avoid repeating the same URL multiple times, unless required and it's your primary CTA

### Buttons

Buttons must be styled manually using the settings below.

#### Primary button

Use the primary button to highlight the most important call to action within the email, ideally limiting it to a single instance to maintain visual hierarchy and emphasis.

<Canvas of={buttonStories.primaryButton} sourceState="none" />

**Settings:**

- Background: `#51247A` (UQ Purple)
- Font colour: `#FFFFFF` (White)
- Border: `#51247A` (Purple), 2px

#### Secondary button

Use the secondary button for actions that are important, but not the primary call to action. It has less visual emphasis than the primary button, helping maintain a clear hierarchy. Secondary buttons can be used multiple times within an email. If all actions are of equal importance, all buttons can be styled as secondary.

<Canvas of={buttonStories.secondaryButton} sourceState="none" />

**Settings:**

- Background: `#FFFFFF` (White)
- Font colour: `#51247A` (Purple)
- Border: `#51247A` (Purple), 2px

#### Button widths

If the button label exceeds 14 characters, increase the button width by 20px to ensure adequate padding on both sides of the text.

**To adjust button width:**

1. Navigate to content section
2. Open **Call to action** panel
3. Scroll down to **width** field
4. Increase width by 20px

**To re-add a deleted button:**

1. Go back to the original template
2. Highlight the button section you want to use
3. Select **copy**
4. Go back to email message and paste the button

### Content sections

Content sections help organize multiple stories or topics in E-newsletters, creating clear visual separation between different content areas.

**When to use content sections:**

Use section headings to help group related content and make it easier to scan. Only add section headings when grouping related content - if everything flows well without them, it's fine to leave them out.

**Guidelines:**

- Use section headings to help group related content, not for individual story headlines
- Aim for no more than four sections
- Use subheadings within sections if needed
- Content sections should be set up with separate section headers instead of using the 'title' component
- Alternate between grey and white background colours to help create clear visual separation between content sections

**Colours:**

- Section background colour: `#F3F3F4` (Grey) or `#FFFFFF` (White)
- Section header colour: `#962A8B` (Light purple)

**Important:** Use only the colours specified to maintain brand consistency across all communications and ensure sufficient colour contrast for accessibility compliance.

**To re-add a deleted content section:**

1. Go back to the original template
2. Highlight the content section you want to use
3. Select **copy**
4. Go back to email message and paste the content section

### Sender header

To help recipients recognise and trust UQ email communications, always use the full name of the area, faculty, school, or office in the sender name, with the acronym in brackets where relevant. This ensures students can quickly identify the source of the message, particularly when communications come from a faculty, school, division, or central office.

The sender name should reflect the area responsible for responding to enquiries related to the email.

**Examples:**

- Faculty of Engineering, Architecture and Information Technology (EAIT)
- Faculty of Health, Medicine and Behavioural Sciences (HABS)
- Business School
- From the Deputy Vice-Chancellor (Academic)
- Institute for Teaching and Learning Innovation (ITaLI)

### Social icons

The template includes default UQ social media links. Update these to reflect your area's official channels. Remove any links that are not relevant, and ensure only one link is shown per platform.

#### To remove a social icon link

1. Select the social icon in the footer
2. Hit **backspace/delete** key

#### To update a social icon link

1. Select the social icon in the footer
2. Select the **Link** option in the WYSIWYG editor toolbar
3. Update the URL
4. Click **Insert link**

#### To add an additional social icon

1. Open the original template
2. Navigate to the contact footer
3. Select and copy the social icon
4. Return to your email message
5. Navigate to the contact footer
6. Press **space twice** to create spacing
7. Paste the icon into the footer
