# Header Analytics Events

The header component emits custom events for analytics tracking. All events bubble and can be listened to at the document level.

## Event: uqds:header:megamenu-toggle

Emitted when a user expands a mega menu dropdown.

**When:** User clicks primary navigation button with dropdown  
**Detail:**
- `action` (string): Always 'expand' (collapse is not tracked)
- `trigger` (HTMLElement): The button element clicked
- `menu` (HTMLElement): The mega menu panel that opened
- `label` (string): Button text (e.g., "Study")

**Example:**
```javascript
document.addEventListener('uqds:header:megamenu-toggle', (e) => {
  console.log('Mega menu opened:', e.detail.label);
  // e.detail.action === 'expand'
  // e.detail.trigger === <button> element
  // e.detail.menu === <div> mega menu panel
});
```

## Event: uqds:header:mobile-menu-toggle

Emitted when the mobile navigation menu is opened or closed.

**When:** User clicks mobile menu toggle button  
**Detail:**
- `action` (string): 'open' or 'close'
- `trigger` (HTMLElement): The toggle button
- `menu` (HTMLElement): The mobile navigation container
- `label` (string): Button text (usually "Menu")

**Example:**
```javascript
document.addEventListener('uqds:header:mobile-menu-toggle', (e) => {
  console.log('Mobile menu', e.detail.action);
  if (e.detail.action === 'open') {
    // Menu opened
  } else {
    // Menu closed
  }
});
```

---

## Event: uqds:header:search-toggle

Emitted when the search panel is toggled.

**When:** User clicks search toggle button  
**Detail:**
- `action` (string): 'open' or 'close'
- `trigger` (HTMLElement): The search toggle button
- `input` (HTMLElement): The search input field

**Example:**
```javascript
document.addEventListener('uqds:header:search-toggle', (e) => {
  console.log('Search panel', e.detail.action);
  if (e.detail.action === 'open') {
    // Search opened, could track time to first keystroke
  }
});
```

---

## Event: uqds:header:search-submit

Emitted when the search form is submitted.

**When:** User submits search form  
**Detail:**
- `searchTerm` (string): User's search query
- `searchScope` (string): 'site' or 'all-uq'

**Example:**
```javascript
document.addEventListener('uqds:header:search-submit', (e) => {
  console.log('Search submitted:', e.detail.searchTerm);
  console.log('Scope:', e.detail.searchScope);
  
  // Push to analytics platform
  dataLayer.push({
    event: 'Search',
    search_term: e.detail.searchTerm,
    search_scope: e.detail.searchScope
  });
});
```

## Integration Notes

### Event Emission Behavior

- All events are emitted **synchronously** with user interactions
- Event emission is wrapped in try/catch for **graceful degradation**
- Events **bubble** to document level for event delegation
- Failed event dispatch logs a console warning but does not break functionality

### Back Button Enhancement

Back buttons in mobile navigation (generated by SlideMenu) are automatically enhanced with `data-gtm-path` attributes after initialization. These attributes contain the hierarchical path context for analytics tracking.

Example:
```html
<a class="slide-menu__backlink" data-gtm-path="Study > Study options">
  < Study
</a>
```

### Template Requirements

For proper analytics tracking, consuming systems should include:

1. **`data-gtm-path` attributes** on navigation links containing parent hierarchy
2. **Hierarchical paths** use ` > ` separator (e.g., "Study > Study with us")
3. **Paths exclude the clicked element** itself (only parent context)
4. **Overview labels** include top-level only (e.g., `data-gtm-path="Study"`)

### Error Handling

All event emission code includes graceful degradation:
- Missing elements are checked before access
- Event dispatch failures log warnings without throwing
- Component functionality continues even if analytics fails

### Browser Support

Custom events are supported in all modern browsers. For older browsers, include a CustomEvent polyfill.

## Complete Integration Example

```javascript
// Listen for all header analytics events
const headerEvents = [
  'uqds:header:megamenu-toggle',
  'uqds:header:mobile-menu-toggle',
  'uqds:header:search-toggle',
  'uqds:header:search-submit'
];

headerEvents.forEach(eventName => {
  document.addEventListener(eventName, (e) => {
    console.log(`Event: ${eventName}`, e.detail);
    
    // Forward to your analytics platform
    if (window.dataLayer) {
      // Transform event detail to analytics format
      // Implementation depends on your analytics requirements
    }
  });
});
```
