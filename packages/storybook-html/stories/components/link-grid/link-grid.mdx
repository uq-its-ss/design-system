## Overview

The link grid component is used to display a collection of links in a grid layout.

### Default

The default link grid layout used to display a collection of links.

### States

Default - Link text is not underlined. <br />
Hover - Link text is underlined. The background and text color may change depending on the variant.

### Breakpoints

Breakpoints have no effect on the link grid component and visually remains the same.

## Accessibility
