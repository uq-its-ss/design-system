# Print

## Overview

The print stylesheet optimises pages for printing. It applies only inside `@media print`, so it has no effect on screen.

To preview it in Storybook, switch the **Media** toolbar item to **Print preview**. This applies the `@media print` rules in the browser; it does not emulate `@page` margins or page breaks, so use your browser's print preview (or DevTools **Emulate CSS media type: print**) for a final check.

<Canvas of={PrintStories.Print} />

## What it does

- Renders text in black on a transparent background and removes shadows.
- Underlines links and appends the URL of external links.
- Appends the `title` of abbreviations.
- Avoids page breaks inside blockquotes, images, preformatted text and table rows, and directly after headings.
- Repeats table headers on each printed page.

## Key Utility Classes Included

- `.no-print`: Add to any element you want hidden exclusively during printing.

- `.print-only`: Add to hidden elements (like a letterhead or copyright footer) that should only appear on paper.

- `.page-break`: Forces a new page before that element.

- `.avoid-break`: Prevents a custom card or callout box from being split across two pages.

## How to use

Import `@uqds/print/src/scss/main.scss` after your other styles so the print rules take precedence.

You can link it in your HTML `<head>` using `<link rel="stylesheet" href="print.css" media="print">` or paste the contents directly inside an `@media print { ... }` block at the bottom of your main stylesheet.
